# CobolTutor: IBM COBOL Tutor

A VSCode extension that explains IBM COBOL code and answers your COBOL questions,
using IBM Granite running locally through Ollama.

- **Explain Selected Code**: select code, right-click, then **Explain Selected Code** (`Ctrl+Alt+E`).
- **Explain This File**: right-click anywhere in a file.
- **Ask questions** in the CobolTutor sidebar. When 📎 is on, your current file or selection is attached.

Requires the CobolTutor backend (`docker compose up -d` in the project repository).
